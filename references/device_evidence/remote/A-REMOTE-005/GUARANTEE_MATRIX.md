# G0-G4 concrete candidate matrix
Candidate: current build-selected ESP-IDF5.5.3 default partition NVS blob keys, root and records in the same rollbackable domain. No durable production control journal implementation exists; Core Journal is an interface, MockJournal counts in-process commits only.

Exact paths/lines and raw hashes: [source excerpts](SOURCE_EVIDENCE.md), [source/SDK identity](SOURCE_SDK_SHA256.json), [SDK snapshots](sdk/nvs_flash/src/nvs_api.cpp). Tests are Python source-informed conservative abstractions, not compiled execution of NVS or proof of flash timing. Full flash-image restoration is in the anti-rollback threat model; random corruption/power-loss are separate covered fault families.

No eFuse writes, external service or new security mechanism selected/implemented. A truly independent monotonic authority is a design dependency, not a software flag.
